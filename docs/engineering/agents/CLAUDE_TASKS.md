# Gestão de Tarefas (Task Breakdown)

Sempre que uma nova funcionalidade ou fase for iniciada, a tarefa deve ser decomposta utilizando a estrutura abaixo:

## Modelo de Tarefa

```markdown
### [TASK-XXX] Nome do Componente / Feature

- **Fase**: [Ex: Fase 1 — Foundation]
- **Dependências**: [Ex: Result, Error]
- **Status**: [Pendente | Em Progresso | Em Revisão | Concluído]

#### Checklist de Execução
- [ ] Leitura da documentação de contexto concluída.
- [ ] Código-fonte implementado.
- [ ] Testes Unitários criados.
- [ ] Testes de Arquitetura criados.
- [ ] Testes de Mutação executados.
- [ ] Documentação (`docs/`) atualizada.
- [ ] Validação final via Definition of Done.
