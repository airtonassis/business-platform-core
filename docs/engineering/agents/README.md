# Engenharia de Agentes de IA - Guidelines

Este diretório contém o conjunto de regras, instruções operacionais e ordens de execução para agentes de IA (como Anthropic Claude, Cursor e GitHub Copilot) que atuam no repositório `business-platform-core`.

## Estrutura de Arquivos

- **`CLAUDE_SYSTEM_PROMPT.md`**: Persona, princípios de engenharia, tom de comunicação e guardrails do agente.
- **`CLAUDE_WORKFLOW.md`**: Fluxo passo a passo (pipeline) de como o agente deve abordar e executar qualquer nova tarefa.
- **`CLAUDE_IMPLEMENTATION_ORDER.md`**: Sequência rígida de dependências e fases de construção da solução.
- **`CLAUDE_TASKS.md`**: Formato padronizado para definição, quebra e rastreamento de tarefas.
- **`CLAUDE_DEFINITION_OF_DONE.md`**: Critérios objetivos que determinam quando uma tarefa está concluída.
